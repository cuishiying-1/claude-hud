# 国际化（i18n）设计

> 放行依据：TASKS.md 延期队列"国际化"为低优先级计划内（用户拍板），`currency_symbol` 配置（⑭）已就绪为基础。
> 范围拍板（2026-08-04 用户确认）：**完整 i18n 框架**（非最小清理）；覆盖**运行时输出 + CLI 帮助文本 + Web 仪表盘页面**三面；语言选择为 **config 显式配置**（默认英文）；语言集可扩展（不只 zh/en）；框架选型 **C 自研轻量**（零新依赖）。

---

## 1. 现状（证据）

- 全项目约 **220 个用户可见字符串，97% 为英文**；中文仅 3 处漏网：`main.rs:62`（clap `--weekly` doc 注释，经 derive 进入 help）、`doctor.rs:268`（`"render 后生效"`）、`serve.rs:292`（网页 JS `'当前模型未配置单价...'`）。
- **无任何 i18n 基础设施**（无 fluent/gettext/locale）；字符串全部内联字面量 + `format!` 拼接。
- 已参数化项：货币符号走 `config.currency_symbol`；widget 占位符统一 `"—"`；通知标题带 emoji 前缀。
- widget 无上下文对象：`Widget trait` 只有 `render_compact(data, theme, config)` / `render_dashboard(data, area, frame, theme, config)`；`WidgetConfig` 在 `src/core/config.rs:265 widget_config(id)` **唯一构建点**。

## 2. 架构

### 2.1 `src/core/i18n.rs`（新文件，零新依赖）

```rust
/// 支持的语言。解析失败 → En（stderr 警告，沿用"坏 config 不静默"先例）。
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Language { En, Zh }

impl Language {
    /// 从 config `language` 字符串解析；未知值返回 None（调用方负责警告）。
    pub fn from_str(s: &str) -> Option<Language>
    /// 语言代码（"en"/"zh"），用于日志与后续扩展。
    pub fn code(&self) -> &'static str
}

/// 查表：当前语言 → En → key 本身（最后兜底，仅当 en 表也缺 key 时触发）。
/// 返回带 `{}` 占位符的模板，调用处 format! 拼接——与现有习惯零迁移成本。
pub fn tr(lang: Language, key: &str) -> &'static str
```

- 字符串表：`locales/en.toml`、`locales/zh.toml`，`include_str!` 编译期嵌入，`OnceLock<HashMap<String, String>>` 惰性解析。
- TOML 分段结构，key 用点分命名空间：`[runtime]`（widget/doctor/notify/dashboard/main 运行时输出）、`[cli]`（clap help）、`[web]`（serve HTML/JS）。段内键名 → 完整 key 如 `"runtime.model"`。
- **en 是全量基准**：代码引用的每个 key 必在 en 表中；zh 允许缺失（缺失回退 en）。单测强制 `zh ⊆ en`（zh 多出的 key 是错拼/笔误，报错列出）。
- **占位符保真**：en 与 zh 共有 key 的 `{}` 数量必须一致（单测强制）。
- **查表逻辑可测**：回退链核心做成纯函数 `lookup(en: &HashMap, zh: &HashMap, lang, key) -> &str`（当前语言 → en → key 本身），`tr` 是加载全局表后的薄封装——单测用合成内存表构造 zh 缺 key 场景，与 `zh ⊆ en` 一致性测试互不矛盾。

### 2.2 配置（用户操作入口）

config.toml 顶层新键（与 `active_mod` 同级，全局生效，同 currency_symbol 模式）：

```toml
language = "zh"   # en | zh（未知值 → stderr 警告 + 回退 en；缺省 en）
```

- 读取点：`config.rs` 顶层解析（`Config::language()` 返回 `Language`，非法值警告一次 + En）。
- 透传：所有入口（render/dashboard/serve/CLI/doctor）从 config 读取后传入输出层。
- **widget 透传**：`WidgetConfig` 增加 `pub lang: Language` 字段（`Default` = En），在 `config.widget_config(id)`（config.rs:265，唯一构建点）注入全局语言——**trait 签名零改动**，14 个 widget 仅在字符串处替换。dashboard tab 标题与 `widget list` 等列表输出在调用方（有 lang）翻译 `"widget.<id>"` 键，`display_name()` 保留英文作为稳定标识。

## 3. 覆盖面接入

### 3.1 运行时输出（~160 条）

替换模式（机械）：

```rust
// 现状
format!("Model: {} ({})", name, id)
// 改造
format!("{}: {} ({})", tr(lang, "runtime.model"), name, id)
```

涉及文件：`src/widgets/*.rs` ×14、`src/doctor.rs`、`src/core/notify.rs`、`src/dashboard.rs`（footer/帮助面板/标题）、`src/main.rs`（setup/uninstall/mod/history 输出）、`src/compact.rs`（错误前缀）、`src/core/update.rs`（四态描述）。3 处中文漏网作为 zh 翻译自然消解。

### 3.2 CLI 帮助（clap，~30 条）

命令名保持英文（shell 补全与文档稳定）；文本走翻译。derive 生成结构不变，构建后逐条注入：

```rust
Cli::command()
    .about(tr(lang, "cli.about"))
    .mut_subcommand("mod", |c| c.about(tr(lang, "cli.mod_about")))
    .mut_arg("pct", |a| a.help(tr(lang, "cli.pct_help")))
```

范围：根 about/after_help + 子命令 about + 参数 help（`mut_subcommand`/`mut_arg` 映射表集中在一个函数）。

### 3.3 Web 仪表盘页面（~25 条）

serve.rs 的 HTML 是 Rust 字符串模板 → 渲染时按语言注入 JS 翻译表，零额外请求：

```html
<script>const T = {title: "Claude HUD 仪表盘", model: "模型", ...};</script>
```

JS 全部字符串改为 `T.xxx` 引用（卡片标题、"used"、"sessions"、JS 内联提示等）；翻译表来自 `[web]` 段，`serve` 进程从 config 读语言。

## 4. 降级与错误处理

- `language` 非法值：stderr 警告 + 回退 En；doctor 增加 `[!!]` 检查项（`language: invalid value 'xx', falling back to en`）。
- 缺 key 回退链：当前语言 → En → key 本身；单测强制 zh ⊆ en 保证 zh 缺失时第一跳有值。
- 默认 En 下所有现有输出字节不变 → 既有黑盒用例零回归（现有断言全英文）。

## 5. 测试策略

### 单测（`src/core/i18n.rs` + 现有模块补充）

- key 集合一致性：`zh ⊆ en`（zh 多出的 key 报错列出）
- 占位符保真：共有 key 的 `{}` 数量一致
- 回退链（`lookup` 合成表）：Zh 缺 key → en 值；en 也缺 → key 本身；En 缺 → key 本身
- `Language::from_str`：`"en"/"zh"` 解析；非法值 None
- widget 侧：至少一个 widget 断言 `WidgetConfig::default().lang == En` 与 lang=Zh 时输出不同

### 黑盒（`scripts/hudlib/cases.py`）

- `language = "zh"`：history 输出含中文表头（`每周统计`/`近期会话`/`每日成本`）
- `language = "zh"`：doctor 输出含中文行（或至少一个代表性断言）
- `language = "xx"`：stderr 含警告 + 输出英文（回退）
- serve：fetch `/` HTML 断言 `const T` 内容随语言变化（zh 含中文卡片标题）
- 默认配置：既有 147 例全量回归（零改动预期）

## 6. 明确不做

- 复数规则（zh/en 均不需要）
- 外部 locale 文件热加载（include_str! 编译期嵌入；加语言需重编译，220 条规模可接受）
- 命令名 / shell 补全脚本翻译
- per-window 语言（config 全局，与现有全局语义一致）
- 数据面翻译（模型名、git 分支、Rhai 脚本输出、notify 中透传的数值等）
