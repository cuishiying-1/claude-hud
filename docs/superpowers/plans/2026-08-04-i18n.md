# 国际化（i18n）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 claude-hud 交付自研轻量 i18n 框架（config `language` 键驱动，en/zh 两张 TOML 字符串表），覆盖运行时输出、clap 帮助与 Web 仪表盘三个面。

**Architecture:** `src/core/i18n.rs` 提供 `Language` 枚举 + `tr(lang, key)`（回退链：当前语言 → en → key 本身）；`locales/en.toml` 为全量基准（值 = 现状字符串原样），`locales/zh.toml` 可缺 key（缺失回退 en）。语言从 config 顶层 `language` 键读取，经 `WidgetConfig.lang`（widget_config() 唯一注入点）与各入口函数参数透传。en 值与原字符串逐字节一致 + 默认 En ⇒ 全部既有单测与黑盒用例零回归。

**Tech Stack:** Rust 2021 · toml 0.8（已有）· clap 4 derive + `Command::mut_subcommand/mut_arg` 后处理 · include_str! 编译期嵌入。

**规范（贯穿全部任务）：**
- **不翻译（通用符号/单位/缩写）**：`ctx` `tok` `k` `min` `s` `%` `5h` `7d` `$`（currency_symbol 动态值）`≈` `—` `│` `·` `█` 频谱字符、图标串（`▸` `◇` `◆` `⬤` `⚡` `✓` `●` `○` `↑` `↓` `*` `>` `[` `]` `🧩` `🔌` `[SK]` `[MC]` `⏱`）、ANSI hex 格式串（`#{:02x}...`）、内部 id/`display_name()`。
- **翻译（词句）**：标签（Model/Branch/Agents/Skills/MCP/Rate Limits/…）、完整句子（通知/doctor/history/setup 输出）、clap help、serve 页面文本。
- **display_name() 保留英文**；dashboard tab 标题与 `widget list` 用 `tr(lang, "widget.<id>")`（dashboard/main 有 lang）。
- **key 命名**：`runtime.*`（运行时输出）、`cli.*`（clap help）、`web.*`（serve）、`widget.<id>`（显示名翻译）。
- 每次 cargo test 后若既有断言失败：检查是否引用被翻译串——en 值 = 原串 + 默认 En，断言应仍通过；若失败是计划缺陷，按实际情况修正并回写。
- **环境**：cargo 不在 PATH，命令必须前缀 `export PATH="$HOME/.cargo/bin:$PATH" &&`；绝不运行 `cargo fmt`；不自动 git 提交（用户手动）。
- 黑盒套件：`python scripts/test_hud.py`（`--case <id>` 单跑）；断言写进 `scripts/hudlib/cases.py` 的 `render_case(...)` 调用，总数在文件末尾 `assert_case_count(...)` 同步。

```rust
use std::collections::HashMap;
use std::sync::OnceLock;

/// 支持的语言。解析失败 → None（调用方警告 + 回退 En）。
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Language { En, Zh }

impl Language {
    pub fn from_str(s: &str) -> Option<Language> {
        match s.trim().to_ascii_lowercase().as_str() {
            "en" => Some(Language::En),
            "zh" => Some(Language::Zh),
            _ => None,
        }
    }

    pub fn code(&self) -> &'static str {
        match self { Language::En => "en", Language::Zh => "zh" }
    }
}

impl Default for Language {
    fn default() -> Self { Language::En }
}

fn load_table(embedded: &'static str) -> HashMap<String, String> {
    toml::from_str(embedded).expect("locale table must parse")
}

fn tables() -> (&'static HashMap<String, String>, &'static HashMap<String, String>) {
    static TABLES: OnceLock<(HashMap<String, String>, HashMap<String, String>)> = OnceLock::new();
    TABLES.get_or_init(|| {
        let en: HashMap<String, String> = load_table(include_str!("../../locales/en.toml"));
        let zh: HashMap<String, String> = load_table(include_str!("../../locales/zh.toml"));
        (en, zh)
    })
}

/// 回退链核心（纯函数，可测）：当前语言 → en → key 本身。
pub fn lookup<'a>(
    en: &'a HashMap<String, String>,
    zh: &'a HashMap<String, String>,
    lang: Language,
    key: &str,
) -> &'a str {
    let table = match lang {
        Language::En => en,
        Language::Zh => zh,
    };
    table
        .get(key)
        .map(String::as_str)
        .or_else(|| en.get(key).map(String::as_str))
        .unwrap_or(key)
}

/// 查表返回模板；调用处 format! 拼接。缺失 key 回退 en → key 本身。
pub fn tr(lang: Language, key: &str) -> &'static str {
    let (en, zh) = tables();
    lookup(en, zh, lang, key)
}

#[cfg(test)]
mod tests {
    use super::*;

    fn table(pairs: &[(&str, &str)]) -> HashMap<String, String> {
        pairs.iter().map(|(k, v)| (k.to_string(), v.to_string())).collect()
    }

    #[test]
    fn from_str_parses_valid_and_rejects_invalid() {
        assert_eq!(Language::from_str("en"), Some(Language::En));
        assert_eq!(Language::from_str("zh"), Some(Language::Zh));
        assert_eq!(Language::from_str("ZH"), Some(Language::Zh)); // 大小写不敏感
        assert_eq!(Language::from_str("xx"), None);
        assert_eq!(Language::from_str(""), None);
    }

    #[test]
    fn lookup_falls_back_zh_to_en_then_key() {
        let en = table(&[("a", "Alpha"), ("b", "Beta")]);
        let zh = table(&[("a", "阿尔法")]);
        // zh 有 → 用 zh
        assert_eq!(lookup(&en, &zh, Language::Zh, "a"), "阿尔法");
        // zh 缺 → 回退 en
        assert_eq!(lookup(&en, &zh, Language::Zh, "b"), "Beta");
        // en 也缺 → key 本身
        assert_eq!(lookup(&en, &zh, Language::Zh, "c"), "c");
        assert_eq!(lookup(&en, &zh, Language::En, "c"), "c");
    }

    #[test]
    fn zh_keys_are_subset_of_en_keys() {
        let (en, zh) = tables();
        let extra: Vec<&String> = zh.keys().filter(|k| !en.contains_key(*k)).collect();
        assert!(extra.is_empty(), "zh 表含 en 没有的 key: {:?}", extra);
    }

    #[test]
    fn shared_keys_have_matching_placeholder_counts() {
        let (en, zh) = tables();
        let count = |s: &str| s.matches("{}").count();
        for (k, ev) in en.iter() {
            if let Some(zv) = zh.get(k) {
                assert_eq!(
                    count(ev), count(zv),
                    "key '{}' 的 {{}} 数量不一致: en={} zh={}", k, ev, zv
                );
            }
        }
    }

    #[test]
    fn tr_returns_en_value_for_default_language() {
        assert_eq!(tr(Language::En, "runtime.doctor_all_passed"), "All checks passed.");
        assert_eq!(tr(Language::Zh, "runtime.history_weekly"), "每周报告（最近 7 天）：");
    }
}
```
